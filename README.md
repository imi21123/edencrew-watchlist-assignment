# 국내 주식 관심종목 — 과제 1

Flutter로 관심·검색·종목상세 화면을 구현했습니다. 기본 실행은 실제 Naver API를 사용하며, 앱을 다시 실행하면 관심 목록은 비어 있습니다.

## 실행

확인 환경: **Flutter 3.47.6 stable / Dart 3.13.5**, Apple Silicon Mac, **macOS 26.6.2 / Xcode 27.0**. macOS 네이티브 앱으로 실행했습니다. Flutter가 생성한 Swift Package Manager 연동으로 `charset_converter`를 연결했습니다.

```sh
flutter pub get
flutter run -d macos
```

Flutter SDK와 Xcode의 첫 실행 설정이 필요합니다. `flutter doctor -v`에서 macOS 개발 환경을 확인할 수 있습니다. Android SDK는 macOS 실행에 필요하지 않습니다.

**VS Code**: Flutter 확장(`Dart-Code.flutter`)을 설치한 뒤 이 프로젝트 폴더를 열고, 실행 및 디버그에서 `macOS · Naver`를 선택해 F5를 누릅니다. SDK가 자동으로 검색되지 않으면 `Flutter: Change SDK`에서 설치한 Flutter 폴더를 선택합니다. 확장 추천 및 실행 설정은 `.vscode/`에 포함했습니다. 개인 SDK 경로 설정은 Git에서 제외합니다.

명시적인 샘플 모드도 제공합니다. 삼성전자·SK하이닉스의 저장된 실제 응답만 사용하며 날짜는 2026-10-02에 고정됩니다. 네트워크 실패 시 샘플로 자동 대체하지 않습니다.

```sh
flutter run -d macos --dart-define=USE_MOCK=true
```

Chrome 실행은 검증 대상이 아닙니다. Naver의 CORS 정책 및 네이티브 문자 인코딩 플러그인 때문에 macOS 실행을 사용해 주세요.

폰트는 스타터의 `NotoSansKR` 400·500·700 OTF와 `pubspec.yaml` 등록을 그대로 사용합니다. 색상과 간격은 `context.colors` / `context.dimens`, 굵기는 `AppTypography`를 참조합니다. 디자인 토큰은 추가하지 않았습니다.

## 구현 범위

- 관심: 종목명·코드·시장·현재가·등락액·등락률, 상승/하락/보합, 초기 시세 스켈레톤, 새로고침, 빈 상태, 정렬 칩·바텀시트, 하단 탭 전환.
- 검색: 입력·지우기, 이름 하이라이트, 관심 등록/해제·토스트, 상세 이동, 검색 전/검색 결과 없음 상태.
- 상세: 헤더·관심 버튼, 현재가·방향 아이콘, 네 가지 기간, 캔들 차트, 시가·고가·저가·거래량·시가총액, 일별 표.
- 공통: 검색·관심·상세가 하나의 관심 상태를 공유합니다. 상세에서 해제하고 돌아오면 관심 목록에서도 사라집니다.
- 선택 구현: 검색 300ms 디바운스, 검색 로딩 표시, 차트 축·거래량·크로스헤어, 관심 행에서 상세 이동, 자동 테스트.
- 제외한 선택 기능: 로컬 저장, 최근 검색어, 스와이프 삭제, 표의 과거 구간 추가 로딩.

기능상 과제 1 필수 항목을 구현했습니다. Figma 캔버스를 기준으로 배치와 상태를 비교했으나, 로그인 없이 열람한 환경에서 텍스트 레이어의 모든 크기·행간을 수치로 대조하지는 못했습니다. 제출 전 본인 Figma 계정의 Inspect에서 수치를 한 번 더 확인할 여지가 있습니다.

과제 2는 이 저장소의 구현 범위에 포함하지 않습니다.

## 구조와 선택 이유

```text
lib/
  data/      HTTP·샘플 소스, 응답 DTO, 종목/시세 저장소
  models/    Stock, Quote, DailyPrice, 기간·정렬 기준
  state/     관심 상태, 검색·상세의 비동기 상태
  screens/   관심·검색·상세·탭 화면
  widgets/   종목 표기, 별 버튼, 빈 상태, 오류, 차트
  utils/     숫자·등락·단위 표기
  theme/     제공된 디자인 토큰
```

- **ChangeNotifier**: 세 화면과 작은 공유 상태에 필요한 갱신을 Flutter 기본 기능으로 처리하고, 저장소를 주입해 상태를 독립적으로 테스트할 수 있습니다. 검색·상세의 로딩은 각각의 컨트롤러가 소유합니다.
- **DTO와 앱 모델 분리**: API 키·응답 형식 변경이 화면 코드로 퍼지지 않게 했습니다. 숫자 문자열·누락·잘못된 응답을 파싱 계층에서 처리합니다. 없는 가격을 0으로 취급하지 않습니다.
- **http**: 10초 요청 제한, 상태 코드 검사, UTF-8 우선 디코딩을 적용합니다. realtime API는 JSON 본문을 `text/plain;charset=EUC-KR`로 보내므로 `Accept: */*`와 `charset_converter`의 네이티브 디코더를 사용합니다.
- **candlesticks 3.0.1**: OHLC 캔들과 기본 차트 상호작용을 사용합니다. 상승은 `chartLineUp`, 하락은 `chartLineDown`이며 패키지의 전체 색상 설정에 제공된 토큰을 전달합니다. 데이터는 패키지가 요구하는 최신 날짜부터의 순서로 전달하고, 기간을 바꾸면 해당 기간 전체가 보이도록 초기 뷰포트를 맞춥니다.

## API와 구간 재사용

Naver endpoint 네 개의 실제 응답을 2026-10-02에 `assets/mock/`에 저장했습니다. 검색은 국내 주식·6자리 숫자 코드를 걸러 `domestic:{symbol}`로 식별하고, 관심 목록 시세는 종목 코드를 묶어 한 번에 요청합니다. 종목 메타데이터는 캐시와 진행 중 요청을 재사용합니다.

스타터 최신 변경 `86d19ed`와 [`docs/NAVER_API.md`](docs/NAVER_API.md)를 기준으로 일별 시세는 HTML이 아닌 **chart API의 JSON**을 사용합니다. 기간은 거래일 수가 아닌 달력의 1·3·6개월/1년이며 월말 날짜를 보정합니다.

일별 캐시는 종목별로 확보한 날짜 구간과 날짜별 OHLCV를 저장합니다. 1개월 → 1년은 부족한 과거 구간만 요청하고, 1년 → 3개월은 다시 요청하지 않습니다. 빠른 기간 전환도 종목별 요청을 직렬화해 중복 구간을 받지 않습니다. 첫 표시 행의 전일 대비를 계산하기 위해 시작일 앞에 14일 버퍼를 요청합니다. 버퍼에도 직전 거래일이 없으면 등락을 `—`로 표시합니다. 당일 캔들은 첫 조회 시점 데이터가 캐시되며, 상세의 재시도는 실패한 요청을 다시 수행하는 용도입니다.

## 시안에 없는 상태에 대한 판단

- 토스트는 등장 애니메이션 후 2초 노출하고 사라집니다. 연속 토글은 이전 토스트를 제거하고 최신 메시지로 대체합니다. 하단 탭 위에 띄우고 화면 이동 때 지워 버튼을 가리지 않게 합니다.
- 최초 시세 수신 전에는 스켈레톤, 조회 실패에는 오류·재시도를 표시합니다. 새로고침 실패 시 이전 성공 가격은 유지하되 오류를 함께 표시합니다. 검색 오류를 '결과 없음'으로 처리하지 않습니다.
- 검색은 300ms 디바운스와 요청 세대 번호로 이전 검색 응답을 무시합니다. 기간 전환에도 세대 번호를 적용해 늦은 응답이 현재 탭의 데이터를 덮어쓰지 않도록 했습니다.
- 긴 종목명은 한 줄 말줄임, 결과 없음 문구의 긴 검색어는 그대로 포함하고 줄바꿈합니다. 큰 가격과 등락이 한 줄에 들어가지 않으면 다음 줄로 넘깁니다. 표는 세로로 스크롤하고 행은 필요할 때 만듭니다.
- 정렬은 현재가·등락률 내림차순, 이름 오름차순입니다. 미수신 가격/등락률은 뒤로 보내며 동률은 종목 코드로 고정합니다. 기본 정렬은 현재가순이고 재실행 시 초기화합니다.
- 누락한 숫자는 `—`, 보합은 `0 (0.00%)`로 구분합니다. 거래량 요약은 천, 시가총액은 조/억 단위로 반올림합니다. 표의 거래량은 원 단위 수치를 쉼표로 표시합니다.

시안과 다른 부분: macOS에는 모바일 상태 바·홈 인디케이터를 그리지 않고 해당 영역의 여백(상단 59, 하단 34)을 확보했습니다. 콘텐츠는 최대 폭 393, 초기 창 콘텐츠 크기 393×852입니다. 창이 작아지면 상세는 스크롤합니다. 아이콘은 Flutter Material 아이콘을 사용합니다. 차트 내부의 눈금, 영어 날짜 축, 거래량, A/L 스케일 버튼, 캔들 간격은 패키지 기본 렌더링이므로 시안과 다르며, 과제 문서의 차트 예외에 해당합니다.

### 막혔던 지점

1. **문서와 초기 계획의 일별 API 차이**: 최신 스타터가 JSON chart API로 개정되어 있어 HTML 파싱 계획을 바꾸고 실제 응답을 먼저 저장했습니다.
2. **realtime의 HTTP 406**: 앱의 `Accept: application/json`이 `text/plain` 응답을 거부했습니다. 실제 macOS 요청에서 재현하고 `Accept: */*`로 수정한 뒤 현재가 수신과 EUC-KR 변환을 확인했습니다.
3. **문자 변환 패키지의 로그**: `charset_converter 2.5.1`의 macOS 구현에서 응답을 두 번 보내는 코드를 확인했습니다. 런타임은 첫 변환 결과를 사용하고 중복 응답을 무시하며 debug 로그에 경고를 남깁니다. 실제 EUC-KR 시세 표시가 정상 동작하는 것을 확인했습니다. 의존성 코드는 변경하지 않았으며 향후 패키지 업데이트 또는 대체를 검토할 부분입니다.
4. **한글 경로의 Flutter 분석 오류**: 설치된 Flutter 3.47.6의 LSP 요청이 문자열 길이를 Content-Length로 사용해 한글 경로에서 분석 서버가 종료됐습니다. SDK 소스에서 원인을 확인했고, SDK를 수정하지 않고 동일 프로젝트의 영문 경로 별칭으로 `flutter analyze`를 실행했습니다. Dart 분석도 별도로 확인합니다. 영문 폴더에 clone하면 일반 명령을 사용할 수 있습니다.

```sh
# 한글 경로에서 위 오류가 발생하는 경우에만 사용하는 예시
ln -s "$PWD" /tmp/edencrew-assignment-analysis
flutter analyze --no-pub /tmp/edencrew-assignment-analysis
```
